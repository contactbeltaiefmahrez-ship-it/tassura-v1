# تسليم موقع TASSURA

الموقع مبني بـPHP8.1+ وMySQL وHTML5 وCSS3 وJavaScript أصلي. جميع الصفحات والطلبات ولوحة الإدارة فعلية، مع قاعدة بيانات وملف إعدادات مركزي، دون أدوات بناء أو ملفات JSON.

## ما أُنجز

الرئيسية ثابتة دون تمرير، وتعرض الفيديوهات الستة عبر ثلاثة مداخل. المتجر يوفّر فلاتر ثابتة وتصفحًا أفقيًا لصور كل منتج. لكل منتج صفحة مستقلة بصور عمودية، وخيارات اللون والمقاس والكمية، ولوحة طلب ثابتة قابلة للتصغير على الهاتف. تتغير معاينة اللون عند اختياره فقط. توجد أقسام الوصف والخامة والعناية والمقاسات والتوصيل، ثم3توصيات.

لوحة الإدارة تشمل تحرير القطع وأسعارها ومخزونها حسب اللون والمقاس، ورفع صور بديلة، ومتابعة الطلبات وتغيير حالتها، والرسائل والحسابات. تُحفظ الطلبات في MySQL ويُخصم المخزون داخل معاملة واحدة. الإلغاء يعيد المخزون مرة واحدة فقط.

## قبل الإطلاق

1. يرفع المبرمج محتوى production إلى استضافةPHP/MySQL ويملأ config/config.php ببيانات OVH الفعلية.
2. يُنشئ قاعدة البيانات ويستخدم install.php لإنشاء حساب المدير الخاص بالمشروع ثم يحذف ملف التثبيت.
3. تُعتمد الأسعار والكميات المتاحة والخامات والمقاسات وبيانات الاتصال والشركة وتكلفة التوصيل. لم تُنقل الأسعار والاتصالات التجريبية من النسخة القديمة.
4. تُراجع شروط البيع والتوصيل والإرجاع الخاصة بالمشروع ويُفعّلHTTPS.

الدفع المدمج هو الدفع عند الاستلام في تونس. لا توجد بوابة دفع إلكتروني أو بيانات مصرفية وهمية. يمكن شراء القطع بعد تعبئة بياناتها الحقيقية وتكلفة التوصيل.

الصورة التي تظهر بعد اختيار بعض الألوان قد تكون للقطعة مطوية، لأنها مأخوذة من صور الألوان التسعة المعتمدة. لا يُستخدم فلتر لتزييف اللون. يمكن استبدال كل معاينة من الإدارة بصورتها الفوتوغرافية المنفردة.

للالتزام بامتدادات الملفات المحددة، تُحفظ الصور والفيديوهات والخطوط داخل حاويات PHP داخلية، ويقدمها media.php للمتصفح بنوعها الأصلي. لا حاجة إلى استخراجها أو تثبيت مكتبات على الاستضافة.

اقرأ INSTALLATION.md للتثبيت وVERIFICATION.md لنتائج الاختبار وحدود التحقق.
